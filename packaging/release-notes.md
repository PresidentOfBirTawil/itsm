## Download Quell

| Your computer | Download | Then |
|---|---|---|
| **Windows** | **Quell-Setup-Windows.exe** | Double-click it and follow the setup wizard |
| **Mac** (Apple silicon) | **Quell-Mac.dmg** | Open it and drag Quell into Applications |
| **Linux** (Ubuntu, Debian) | **Quell-Linux.deb** | Double-click it to install |

Then open **Quell** from the Start menu, the desktop shortcut or Applications. It opens in your browser.
Nothing else is needed: Java is included and no internet connection is required.

**Would rather not install anything?** Download the *Portable* file for your computer, unzip it and
double-click **Quell** inside.

**Windows says "Windows protected your PC"?** Click **More info**, then **Run anyway**. This appears
for new applications that are not yet signed with a paid certificate.

**Mac says Quell "cannot be opened"?** Right-click Quell in Applications and choose **Open**, then
**Open** again. You only need to do this once.

**First steps:** on the sign-in page, click one of the demo accounts to look around, or see the
[getting-started guide]({{GUIDE}}).

This release is rebuilt automatically from the latest code.
