# Test cases {#appendix-b .appendix .landscape}

The thirty-six documented test cases. Each names the automated test that carries it out, so it can be checked against the code in `src/test/java/com/itsm`; all of them pass. TC-01 to TC-20 cover the mandatory modules, TC-21 to TC-36 the intelligent features, the assistant, attachments, the API, webhooks and security.

## The exception cases of the brief

Every exception case of the brief is raised by at least one test and turned into a readable message or page by another.

::: {.keys .compact}
| Case                       | Exception class                              | Tests                                                             |
|----------------------------|----------------------------------------------|----------------------------------------------------------------------|

| Technician unavailable | `TechnicianUnavailableException` | `IncidentWorkflowTests.anIncidentCannotBeGivenToAnUnavailableTechnician` (TC-09), `ErrorHandlingTests.assigningToAnUnavailableTechnicianComesBackAsAMessage` |
| Workload exceeded | `WorkloadExceededException` | `IncidentWorkflowTests.anIncidentCannotBeGivenToATechnicianAtMaximumWorkload` (TC-08), `ErrorHandlingTests.assigningToATechnicianAtTheirMaximumComesBackAsAMessage` |
